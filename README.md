## Backend & Architecture

- Node.js, TypeScript, NestJS, Fastify, Express, Python and PHP
- REST APIs, Swagger/OpenAPI and asynchronous processing
- Microservices, event-driven architecture and provider integrations
- Idempotency, retry, DLQ, Saga and Strangler migration patterns
- Jest, Vitest, integration tests and contract validation

## Databases & Persistence

- MySQL, MariaDB and PostgreSQL
- Redis/Valkey for cache, coordination and temporary state
- Data modeling, query analysis, indexes and connection pooling
- Transaction boundaries, reconciliation and consistency between services

## Cloud & DevOps

- AWS EKS, Lambda, API Gateway, SQS, CloudWatch, X-Ray, SSM and Secrets Manager
- Docker, Kubernetes, Helm, GitOps and Argo CD
- CI/CD pipelines, health checks, autoscaling and feature flags

## Telecom (BSS/OSS)

- MVNO, M2M/IoT and dual-network connectivity
- Identity-compliance workflows and operational reconciliation

- Operational dashboards and API-driven interfaces

- Legacy frontend maintenance and incremental modernization
